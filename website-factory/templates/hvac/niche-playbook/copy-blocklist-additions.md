# HVAC Copy Blocklist Additions

## Purpose

These words and phrases are banned from all client-facing copy in the HVAC template. This list supplements any global blocklist in the factory. If a word appears here, do not use it in headlines, body copy, CTAs, meta descriptions, or alt text.

## Banned Marketing Buzzwords

- leverage
- synergize
- robust
- seamless
- cutting-edge
- game-changer
- best-in-class
- world-class
- turnkey
- disruptive
- innovative (unless describing a specific patented feature)
- revolutionary
- next-generation
- paradigm
- holistic
- proactive (use "preventive" instead)
- optimize (use "improve" instead)
- utilize (use "use" instead)
- facilitate (use "help" instead)
- implement (use "install" or "set up" instead)

## Banned AI and Tech Jargon

- AI-powered (never in client-facing copy)
- machine learning
- algorithm
- neural network
- smart technology (unless referring to a specific smart thermostat product)
- IoT
- ecosystem
- platform
- digital transformation
- automation (unless describing a specific thermostat feature in plain terms)

## Banned Pressure Tactics

- "Act now before it is too late"
- "Limited time offer" (unless there is a real, dated promotion)
- "Only X slots left" (unless genuinely true and verifiable)
- "You can not afford to wait"
- "Do not make this mistake"
- "What they do not want you to know"
- Any countdown timer tied to a fake deadline

## Banned Vague Claims

- "quality service" (say what makes it quality)
- "great customer service" (show it with reviews instead)
- "top-rated" (say rated where and by whom)
- "trusted" (show why with numbers and badges)
- "the best" (say best at what, backed by data)
- "affordable" without context (give a price range or "starting at" figure)
- "fast" without context (give a time frame)

## Banned Formatting

- Em-dashes. Use commas, periods, or colons instead.
- Emojis. Never in any output.
- ALL CAPS for emphasis in body copy. Use bold or a heading instead.
- Exclamation marks in headlines. One per page maximum in body copy, and only if genuinely warranted.

## Replacement Guide

| Banned | Use Instead |
|---|---|
| leverage | use, apply |
| utilize | use |
| facilitate | help, make possible |
| implement | install, set up, start |
| optimize | improve, tune |
| robust | strong, reliable, durable |
| seamless | smooth, easy |
| cutting-edge | modern, current, up to date |
| innovative | new, improved, [specific feature name] |
| proactive | preventive, planned |
| affordable | starting at $X, monthly payments available |
| fast | same-day, within X hours, within X minutes |
